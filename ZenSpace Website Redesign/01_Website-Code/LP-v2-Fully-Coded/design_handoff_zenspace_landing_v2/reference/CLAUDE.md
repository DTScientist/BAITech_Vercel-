## 6. Service Model — Verified Process

### Before the Event
- Dedicated onboarding and event alignment
- Pod count, schedule, floor plan, and branding reviewed with a specialist
- Client provides power; ZenSpace handles delivery, install, testing, and support

### During the Event
- Live support plus real-time dashboard
- AI alerts for occupancy, open doors, and loitering
- Remote content updates available

### After the Event
- Pods removed within hours of show close
- Complete utilization report delivered with bookings and lead data
